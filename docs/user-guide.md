# Руководство пользователя: как сделать заказ в кафе

Версия: 0.1 | Дата: 21.10.2026

## Для кого это руководство
Для студентов и сотрудников университета, которые впервые пользуются терминалом самостоятельного заказа в кафе.

## Пошаговая инструкция
1.  Подойдите к сенсорному терминалу у входа в кафе
2.  Просмотрите меню, выберите нужные блюда, нажмите «Добавить в заказ»
3.  Откройте корзину, проверьте состав и общую сумму заказа
4.  Оплатите заказ банковской картой через терминал
5.  Дождитесь появления номера заказа на экране, получите блюдо на раздаче по номеру

## Частые проблемы
| Симптом | Что делать |
|---|---|
| Блюдо не добавляется в корзину | Проверьте, что оно есть в наличии на витрине |
| Оплата не проходит | Обратитесь к сотруднику кафе |
| Блюдо не выдают | Назовите номер заказа с экрана |
